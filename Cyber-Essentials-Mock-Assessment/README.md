# Cyber Essentials — Mock Security Assessment

**Project:** Small Clothing Brand Security Assessment  
**Assessment Type:** Cyber Essentials Mock Assessment  
**Environment:** Small business using Windows 11, cloud-based services, social media and mobile internet connectivity  
**Status:** Assessment completed; remediation partially outstanding

## Overview

This project documents a mock Cyber Essentials security assessment conducted for a fictional small clothing brand.

The objective was to evaluate the organisation's basic cybersecurity controls, identify security weaknesses and recommend improvements based on the five Cyber Essentials technical control areas.

## IT Environment

The fictional business used:

- A Windows 11 laptop for daily business operations.
- Instagram and TikTok for marketing and customer engagement.
- Browser-based services and a dedicated business email account.
- An iPhone mobile hotspot for internet connectivity.

## Cyber Essentials Controls Reviewed

| Control | Assessment Focus |
|---|---|
| Firewalls | Reviewing firewall rules and network access |
| Secure Configuration | Reviewing system settings and unnecessary services |
| Security Update Management | Reviewing operating system and application updates |
| User Access Control | Reviewing account permissions and password practices |
| Malware Protection | Reviewing endpoint protection arrangements |

## Key Findings

The assessment identified several security weaknesses:

**1. Unnecessary FTP firewall rule**

An unnecessary FTP-related firewall rule was identified and resolved to reduce the potential network attack surface.

**2. Excessive administrator privileges**

The business laptop was being used with administrator privileges for routine activities. This was addressed to support the principle of least privilege.

**3. Predictable mobile hotspot password**

The mobile hotspot used a predictable password, which was changed to improve network access security.

**4. Password reuse**

Password reuse was identified across Windows and business accounts. Some remediation remained incomplete at the end of the assessment.

## Recommendations

- Remove unnecessary firewall rules and services.
- Use standard user accounts for everyday activities.
- Maintain strong, unique passwords for business accounts.
- Enable multi-factor authentication wherever supported.
- Keep operating systems and applications updated.
- Maintain appropriate malware protection.
- Periodically review security configurations and user permissions.

## Outcome

The mock assessment demonstrated how Cyber Essentials controls can be applied to a small business environment.

Several weaknesses were identified and addressed, while some password-related issues required further remediation.

The assessment did not establish full Cyber Essentials compliance or result in an official certification.

## Key Learning

This exercise strengthened my understanding of how to evaluate technical security controls, document findings and recommend practical improvements for a small organisation.

It also demonstrated the importance of verifying remediation before considering an assessment complete.
