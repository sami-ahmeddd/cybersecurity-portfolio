# Cybersecurity Portfolio

## About Me

I'm a First-Class BSc (Hons) Computer Science graduate from the University of Huddersfield, currently undertaking a Cyber Security Internship at Yottabyte Cybersecurity.

My interests include Security Operations (SOC), threat detection, vulnerability assessment and penetration testing.

This portfolio documents my practical cybersecurity training, laboratory exercises and security assessments.

## Projects

### 1. PortSwigger Web Security Academy

[View PortSwigger Labs](./PortSwigger-Academy/)

Practical web application security exercises covering:

- SQL Injection — Hidden Data Retrieval
- SQL Injection — Authentication Bypass
- Reflected Cross-Site Scripting (XSS)
- Stored Cross-Site Scripting (XSS)

Includes a technical walkthrough explaining how SQL Injection can bypass authentication.

### 2. DVWA — Web Application Security Testing

[View DVWA Assessment](./DVWA-Security-Testing/)

Security testing using Damn Vulnerable Web Application (DVWA), covering:

- SQL Injection and Blind SQL Injection
- Reflected XSS
- Command Injection
- File Upload
- Cross-Site Request Forgery (CSRF)
- Brute Force
- Weak Session IDs
- File Inclusion
- Insecure CAPTCHA

The project compares Low and High security configurations, documents observed results and discusses recommended mitigations.

### 3. Cyber Essentials — Mock Security Assessment

[View Cyber Essentials Assessment](./Cyber-Essentials-Mock-Assessment/)

A mock security assessment of a fictional small clothing brand against the five Cyber Essentials technical controls:

- Firewalls
- Secure Configuration
- Security Update Management
- User Access Control
- Malware Protection

Includes identified security weaknesses, remediation activities and recommendations.
